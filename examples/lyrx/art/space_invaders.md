# Space Invaders

A program using a mirrored [modified random walk](https://en.wikipedia.org/wiki/Random_walk) to generate space invaders. This algorithm works for both big and small space invaders. On the bigger scale you can get some very interesting shapes which are more akin to [Rorschach tests](https://en.wikipedia.org/wiki/Rorschach_test) than anything else. Over all I had a lot of fun making this and seeing all the patterns it can create.

This works was done for a [coding challenge hosted by Creative Coding Amsterdam](https://cca.codes/code-jams/space-invaders/).

**The code that generated it:**
